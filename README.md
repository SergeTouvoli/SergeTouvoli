### 🇨🇮 EmploiCiv

EmploiCiv is one of my largest and longest-running personal projects.

I originally started the project in **2022**, when I was still learning a lot of the fundamentals of web development.

The first version was built almost entirely from scratch using **native PHP and vanilla JavaScript**. Over time, I kept improving it until I had a relatively stable and functional version.

As my development skills evolved, I wanted to use the project as an opportunity to learn more about modern application architecture.

In **2024**, I therefore decided to rewrite the application from scratch using **Symfony**.

Instead of simply abandoning the original codebase, the project became a way for me to measure my own progression: going from a native PHP application built in 2022 to a structured Symfony application with a clearer architecture and a more maintainable codebase.

EmploiCiv is a job platform focused on the **Ivorian market**, designed to connect companies and job seekers and provide businesses with tools to publish and manage job opportunities.

It remains an important personal project for me, both as a product and as a record of how my development skills have evolved over the years.

**Started:** 2022  
**Major rewrite:** 2024  
**Stack:** Symfony · PHP · MariaDB · Docker

🌍 **[emploiciv.com](https://emploiciv.com/)**

### 🐾 Canaille

Canaille is an interactive Docker Compose inspector and linter written in Go.

It parses Compose files, provides an interactive terminal interface to explore services, and aims to detect configuration issues, security concerns and potentially unsafe Docker settings.

I'm building Canaille while learning **Go** and improving my understanding of Docker, networking and DevOps.

The project is named after my Shih Tzu, Canaille. 🐶
